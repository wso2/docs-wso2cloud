# Security overview

Choreo Labs builds Choreo Cloud with a privacy-by-design and security-by-default approach. This page summarizes the controls and commitments that apply, and links to the authoritative sources.

## Compliance

Compliance certifications for Choreo Cloud are in progress. For WSO2's current certifications and their scope, see [Choreo Labs Compliance](https://choreolabs.com/security/compliance).

## Data privacy

- WSO2 supports GDPR and CCPA obligations, and offers a Data Processing Agreement (DPA).
- WSO2 is certified under the EU-U.S. Data Privacy Framework.
- WSO2 publishes the subprocessors it uses to deliver its cloud services.

For details, see [Data Privacy and Protection](https://choreolabs.com/security/data-privacy-and-protection) and the [public cloud subprocessor list](https://wso2.cachefly.net/wso2/sites/all/trust/wso2-public-cloud-subprocessor-list.pdf).

## Service security

- **Tenant isolation.** Each organization is an isolated tenant. Its resources can't be reached from another organization.
- **Separated planes.** Runtime traffic stays in the data plane. Traffic between the control plane and the data plane is encrypted with TLS. See [Data planes](../architecture/data-planes.mdx).
- **Alert notifications.** Webhook secret headers and mail server logins in notification channels are stored in a secret store and are write-only. Webhooks and mail servers must be public hosts, so alerts can't be sent to internal addresses. See [Set up notification channels](../observability/notification-channels.mdx).
- **Least-privilege access.** Add people to the **Admin** group only if they administer the organization, and give everyone else the group that matches their job. See [Access control](../manage/access-control.mdx).
- **Enterprise sign-in.** Let people sign in with your own OpenID Connect identity provider, so your sign-in policies apply to Choreo Cloud. See [Set up enterprise sign-in](../manage/enterprise-sign-in.mdx).
- **Audit logs.** Changes in API Management are recorded with the user, the action, the resource and the time. Organization admins can request their organization's audit logs. See [Audit logs](../manage/audit-logs.mdx).
- **Security contacts.** Choreo Labs notifies your security contacts about security incidents, vulnerability disclosures, and critical patches. See [Manage service contacts](../manage/manage-service-contacts.mdx).

Choreo Labs' cloud security processes are described in the [Choreo Labs Security documentation](https://security.docs.choreolabs.com/en/latest/security-processes/cloud-security-process/).

## Report a vulnerability

To report a security issue, follow the process on the [Choreo Labs Security](https://choreolabs.com/security) page.
