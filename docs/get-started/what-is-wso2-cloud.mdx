# What is WSO2 Cloud?

WSO2 Cloud is the fully managed SaaS way to use WSO2's platforms. Register once and you get the platforms already provisioned, pre-integrated, and operated for you, all under one Organization and one bill.

## The agentic enterprise fabric

WSO2 builds the **agentic enterprise fabric**. It is a set of platforms that enterprises standardize on to build, connect, secure, run, and observe software at scale. The fabric covers APIs, integrations, identity, analytics, and AI agents, and each of these is a full capability in its own right.

You can run these platforms in three ways:

| Deployment model | Who runs the infrastructure | Who runs the control plane |
| --- | --- | --- |
| **Self-managed** | You | You |
| **Hybrid** | You | WSO2 |
| **SaaS (WSO2 Cloud)** | WSO2 | WSO2 |

WSO2 Cloud is the SaaS option. You don't need to install, upgrade, or operate anything, and the platforms arrive already connected to each other.

## Why a fabric, not separate products

Enterprise software often fails in production because of the capabilities around it, not the software itself:

- An API needs identity and analytics to be secure and observable.
- An integration needs to be exposed and governed.
- An AI agent needs all of these.

These platforms work best woven together, not bought one at a time and stitched together later. The fabric gives platform teams a composable foundation to standardize on, so that every kind of software, including AI agents, is built, run, and governed the same way across the enterprise.

AI agents make this more urgent. An agent is only as ready as the identity, integrations, APIs, and observability around it. The fabric serves the whole portfolio equally, though. It works just as well if you want to publish APIs, connect systems, manage identity, understand usage, or run agents. WSO2 Cloud delivers that fabric as SaaS.

## Our vision

WSO2 Cloud aims to be the default cloud for enterprises to build, run, and govern software and AI agents. It brings identity, integration, APIs, analytics, and agent infrastructure together as one enterprise-grade cloud.

Capabilities that used to need large platform teams become available right away to organizations of every size, from startups to global enterprises.
