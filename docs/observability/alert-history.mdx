# View alert history

This article shows you how to see the alerts your alert rules fired. To learn how alerts work, see [Alerts](./alerts.mdx).

## Prerequisites

- Membership in the **Admin**, **Platform Engineer**, **Developer**, or **Viewer** group of the organization.

## View alerts

1. Sign in to the [WSO2 Cloud console](https://console.cloud.wso2.com).
2. In the left navigation, select **Observability**, then **Alerts**.
3. Select the **History** tab.

The tab lists the alerts from the last 24 hours, newest first. Each row shows:

| Column | What it shows |
| --- | --- |
| **Time** | When the alert fired, in UTC. |
| **Alert** | The name of the rule that fired. |
| **Severity** | **Info**, **Warning**, or **Critical**. |
| **Project**, **Component**, **Deployment track**, **Environment** | Where the alert fired. |
| **Value** | The measured value, with the rule's threshold under it. |
| **Channels** | The channels the alert was sent to. **No channel** means it wasn't sent, because the rule had no channel in that environment. |

## Filter alerts

- **Time range.** Select **Time** to pick **Last hour**, **Last 24 hours**, **Last 7 days**, or **Last 30 days**, or a custom range of up to 30 days. Times are in UTC.
- **Search.** Use **Search by alert name** to find a rule's alerts.
- **Columns.** Filter by **Severity**, **Project**, **Component**, **Deployment track**, or **Environment**. Select a project before filtering by component, and a component before filtering by deployment track.

To see one project's alerts only, select the project in the top bar. To get the latest alerts, select the refresh icon.

If a time range has many alerts, the tab shows the latest ones first. Select **Load older alerts** to see more. The search and the severity filter only apply to the alerts that are loaded.
